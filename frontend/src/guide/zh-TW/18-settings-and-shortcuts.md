# 設定、備份與快捷鍵

![設定](/guide/18-settings.png)

## 屬於你的

主題（淺色或深色）、語言、強調色、日期與時間格式、清單密度，以及專案預設用哪個檢視打開。這些存在你的帳號上，所以會跟著你到任何一台你登入的機器。

### 藏起選單列

把你不用的部分關掉，剩下的拖成你要的順序。

有三列藏不掉：**總覽**、**使用說明**和**設定**。當你剛把選單修得太乾淨時，那三列是你找得回來的路。

## 你的行事曆

**行事曆訂閱**是一個涵蓋所有有到期日的東西的訂閱網址。貼進 Google 行事曆、Apple 行事曆或 Outlook，你的期限就會出現在那裡，而且自己更新。

把它當憑證看待：任何拿到網址的人都讀得到。它可以重新產生，舊的就會失效。

## 排程

- **摘要時間** —— 每日摘要信什麼時候寄出（UTC）。
- **即將到期的時間窗** —— 距離到期還有多久時觸發提醒。
- **提醒冷卻時間** —— 同一個任務隔多久才會再提醒你一次。

每一項都有範圍，而那個範圍是伺服器從「存檔時強制執行的同一條規則」送出來的——所以頁面不可能給你一個存檔時會被默默夾掉的值。

每週摘要在星期幾寄，是在伺服器設定裡定的，不在這裡。

## 備份

備份每天自動跑一次，保留最近幾份——時間和保留幾份由你決定。你也可以：

- **現在跑一次。**
- **下載一份。** 這是整個資料庫，權杖和金鑰都在裡面。放在安全的地方。
- **從某一份還原。** 這會取代你現在的資料，所以它會要你打字確認。

## AI 供應商

助理用哪個模型，在〈助理〉那一章講過。它在下一則訊息生效，不用重啟。

## 系統狀態

你的版本、資料庫，以及哪些選用功能開著。這一塊是回報 bug 時該貼上的內容——版本是從伺服器送到這一頁的，所以它寫的是**真正回應你的那個 build**，而不是你以為部署上去的那份程式碼。

## 鍵盤快捷鍵

| 按鍵 | 做什麼 |
|---|---|
| `?` | 顯示所有快捷鍵，並提供這一頁的導覽 |
| `Ctrl-K` / `Cmd-K` | 搜尋所有東西 |
| `/` | 跳到搜尋 |
| `C` | 建立任務 |
| `N` | 建立專案 |
| `G` 再 `H` | 首頁／總覽 |
| `G` 再 `P` | 切換專案 |
| `G` 再 `A` | 分析 |
| `G` 再 `I` | 身分 |
| `G` 再 `G` | 目標 |
| `Esc` | 關掉打開的東西 |

## 去哪裡找幫助

![使用說明](/guide/27-guide.png)

- **每一頁左下角那顆羅盤按鈕。** 它會帶你走一遍你現在這一頁，一個一個指出每個控制項。上面有一個點，表示那一頁的導覽你還沒走過。
- **這份使用說明**，在選單裡。它的側欄也把所有導覽列在一起，走過的旁邊會打勾，所以第一天可以拿它當檢查清單用。
- **`?`** 看快捷鍵，以及走一遍你現在站的地方。

## 離線工作

如果你的連線斷了，app 還是能用。你做的改動會排在本機的佇列裡，等你回來時照你做的順序送出去。畫面底部有一個指示器告訴你現在離線，以及有幾個改動在等。

佇列送出時被伺服器拒絕的東西會被丟掉，而不是永遠重試——所以一個已經不成立的改動，不會把整個佇列卡在它後面。
