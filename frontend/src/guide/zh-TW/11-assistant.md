# 助理

一個能讀、也能改你真實資料的聊天視窗。

![助理](/guide/12-assistant.png)

## 它實際做得到什麼

它不是一個講話比較親切的搜尋框。它有一組工具，而且真的會用：

- 總結目前的狀況
- 列出並篩選任務
- **建立**任務和子任務
- **修改**任務——狀態、優先度、日期、指派
- 加上和移除標籤
- 分析你的工作量，告訴你負擔集中在哪裡
- 搜尋所有東西
- 讀活動歷史

所以「建一個任務在 30 號前續網域，高優先」會產生一個任務。「客戶那邊有什麼逾期了？」會產生一份你真正的任務清單。

## 兩個地方，同一個助理

選單裡有一個完整的頁面，任何畫面上也都能叫出一個浮動面板。它們是同一個東西——同樣的對話、同樣的能力、同樣的建議問句。你已經在頁面上時，面板會自己隱藏。

## 對話會留著

每一段對話都會存下來、也搜尋得到，所以助理上週跟你說過什麼，都還在。`+` 開一段新的。

## 選它用哪一家 AI

到**設定 → AI 供應商**。選供應商、貼上 API 金鑰、指定模型。

這會在你的**下一則訊息**生效。不用重啟，也不用重新部署。

有兩件事值得知道：

- **「供應商」是一種協定，不是一家公司。** 它的意思是「這個端點講的是 Anthropic API 那個形狀」或「這個講的是 OpenAI API 那個形狀」。那個選填的 base URL 欄位讓你把任一種指向別的地方——一個 gateway、一個代理，或你自己架的相容伺服器。
- **模型名稱會被檢查，但很溫和。** 存檔的時候，Shard 會去問供應商那個模型存不存在。如果問不到——沒網路、或那個端點不提供模型清單——它還是會存起來，標記成「未驗證」，而不是拒絕你。

如果沒有設定供應商，助理會直接說，而不是假裝在回答。

## 公開分享頁上的助理

專案的公開頁面上有它自己的唯讀助理。它可以回答關於這個專案的問題，而且它**只看得到那一頁本來就顯示的東西**。它不能建立任何東西，也讀不到訪客往下捲就看不到的內容以外的資料。
