# 標籤、衝刺、批次修改與樣板

當專案裡有了真正的工作之後，讓它跑得更快的那些部分。

## 標籤

標籤就是一個帶顏色的標記：`bug`、`等客戶回覆`、`待審`。從專案標題區的**標籤**按鈕管理清單，再從任務的編輯列套用。

標籤是各專案獨立的，所以一個專案的「緊急」不是另一個專案的「緊急」。在任何檢視的篩選列上都可以照標籤篩。

## 衝刺（Cycles）

![衝刺分頁](/guide/19-project-cycles.png)

衝刺是一段有名字的時間窗——「Sprint 14」、「十月」——任務可以歸屬到它。在專案裡打開 **Cycles** 分頁建立一個，設好起訖日期，再把任務加進去。

專案有了衝刺之後，兩件事會解鎖：

- 分析頁上的**燃盡圖**：剩下多少工作，一天一天地畫，對照一條直直降到零的線。它告訴你是超前還是落後。
- **速度**：你在過去每一個衝刺實際完成了多少。跑過三四個衝刺之後，這個數字比任何估計都更適合拿來規劃下一輪。

你也可以**複製**一個衝刺，把它的形狀沿用到下一輪。

## 批次修改

在 Issues 分頁上，從篩選列打開選取模式。每一列都會出現核取方塊。選幾個之後會冒出一條工具列：設狀態、設優先度、釘選。

這是把一批做完的東西一次結掉、或把客戶剛抱怨的所有事一次提高優先度，最快的方法。

## 匯入與匯出

**匯出**把專案的任務寫成一個 JSON 檔。**匯入**把它讀回來。兩個合起來是一次來回：你可以匯出一個專案、編輯那個檔案，再匯入另一個專案。

匯入器也讀得懂 **Trello、Linear 和 GitHub** 的匯出檔。它會回報它做了什麼——匯入幾筆、跳過幾筆、每一筆失敗是為什麼——而不是因為一列資料怪怪的就放棄整批。

## 樣板

![樣板](/guide/21-templates.png)

樣板就是你一直在重建的那種任務，連零件一起存起來：它的子任務、標籤、預設優先度。

「接一個新客戶」可能是一個帶八個子任務的樣板。「發一個版本」可能有五個。在樣板頁做一次，之後套用到任何專案，它會一次建好那個任務和所有子任務。

樣板是跨專案共用的，所以你為某個客戶寫的樣板，下一個客戶也用得到。
