# 把工作分享給外面的人

分享連結給某個人一個專案或身分的唯讀網頁。他不需要帳號，也改不了任何東西。

![分享出去的專案頁面](/guide/25-share-page.png)

## 打開它

在專案標題區點**分享**（身分的話是設定按鈕）。一塊面板裡就有全部：

| 控制項 | 做什麼 |
|---|---|
| **連結** | 公開網址。複製後傳出去。 |
| **重新產生** | 換一個新網址。舊的立刻失效。 |
| **PIN 碼** | 訪客要先輸入的密碼。 |
| **到期日** | 過了這天連結就不能用了。 |
| **訪客留言** | 讓訪客不用帳號就能留一則訊息。 |
| **瀏覽次數** | 這個頁面被打開過幾次。 |
| **行事曆訂閱** | 到期日的訂閱網址，給 Google／Apple 行事曆用。 |

## 訪客看得到什麼

任務、它們的狀態和到期日、標籤、衝刺、留言、相依——以及**這個專案的決策記錄**，連同它們的取代鏈和它們管轄的工作。

決策出現在公開頁面上是有原因的。最可能問「這件事為什麼長這樣？」的人，就是當時不在場的那個人，而那正是這個頁面服務的對象。

頁面上還有一個唯讀助理。它可以回答關於這個專案的問題，而且它只看得到頁面本來就顯示的東西。它不能建立任何東西。

## 實務上的幾點

- **重新產生會弄壞舊連結。** 建在它上面的行事曆訂閱也會失效。那正是「重新產生」的用途——當一個連結流到了不該去的地方時用它。
- **PIN 碼對頁面上的所有東西都有效**，包含留訪客訊息。它不是繞過那道門的方法。
- **連結本身就是憑證。** 任何拿到它的人都讀得到這個頁面，所以請把它當密碼看待；當它要去一個你控制不了的地方時，加上 PIN 碼和到期日。
