# 把工作分享給外面的人

分享連結給某個人一個專案或身分的唯讀網頁。他不需要帳號，也改不了任何東西。

![分享出去的專案頁面](/guide/25-share-page.png)

## 打開它

在專案標題區點**分享**（身分的話是設定按鈕）。一塊面板裡就有全部：

| 控制項 | 做什麼 |
|---|---|
| **連結** | 公開網址。複製後傳出去。 |
| **重新產生** | 換一個新網址。舊的立刻失效。 |
| **PIN 碼** | 訪客要先輸入的密碼。 |
| **到期日** | 過了這天連結就不能用了。 |
| **訪客留言** | 讓訪客不用帳號就能留一則訊息。 |
| **瀏覽次數** | 這個頁面被打開過幾次。 |
| **行事曆訂閱** | 到期日的訂閱網址，給 Google／Apple 行事曆用。 |

## 訪客看得到什麼

任務、它們的狀態和到期日、標籤、衝刺、留言、相依——以及**這個專案的決策記錄**，連同它們的取代鏈和它們管轄的工作。

決策出現在公開頁面上是有原因的。最可能問「這件事為什麼長這樣？」的人，就是當時不在場的那個人，而那正是這個頁面服務的對象。

還有一張**結構圖**：跟「結構」頁畫給你看的是同一張地圖，用這個連結本來就帶著的東西畫出來。什麼裝著什麼、哪個任務在等哪個任務、哪一筆決策管轄哪件工作——這些關係頁面其他地方都是用文字說的，而且一次只說得出一端。選一個節點，它沒碰到的東西會暗下來。三種版面，縮放控制擺在那裡是因為大專案第一眼會被縮到符合框寬。

摘要下方的**分析**區，第一張是**地形圖**：整個分享是一片山脈，每個專案是其中一座高峰，和相鄰的峰之間由稜線相連。高峰的寬度是它全部的任務數，高度是還沒完成的任務數，線條越亮代表最近 30 天越忙；峰與峰之間較暗的丘陵不屬於任何專案。山的位置也有意義：左到右是距離上次有動靜多久（最左邊是 90 天以上，最右邊是今天），後到前是完成了多少。所以在右前方的山是最近有動、快做完的；在左後方的是還沒碰過的。任務是坡面上的小方框，指到方框或山頂就會顯示內容。**Map** 用等高線從上方畫出這片地形；**3D** 從接近正上方用透視畫出同一片地形：拖曳可以移動，滾輪（手機上用雙指捏合）可以放大擠在一起的地方，按住 Shift 拖曳可以旋轉和調整傾斜，雙擊回到預設視角；**Timeline** 顯示每個專案在什麼時候忙。專案超過八個時，最小的那些會併成一片低矮的丘陵，標出它包含幾個專案。

地形圖下面是分析頁本身的圖表：一年的活動、狀態趨勢、衝刺燃盡、速度。每張只在有東西可看時才出現，一條從沒動過的燃盡線會直接省略，而不是畫成一條平線。

頁面最上方捲動的那條，是大家最近對這些工作做了什麼；系統自己做的事（規則觸發、提醒、頁面瀏覽）不會出現在裡面。

頁面上還有一個唯讀助理，停在右下角（導覽列上的 **ASK** 也可以把它叫起來）。它可以回答關於這個專案的問題，而且它只看得到頁面本來就顯示的東西。它不能建立任何東西。

## 實務上的幾點

- **重新產生會弄壞舊連結。** 建在它上面的行事曆訂閱也會失效。那正是「重新產生」的用途——當一個連結流到了不該去的地方時用它。
- **PIN 碼對頁面上的所有東西都有效**，包含留訪客訊息。它不是繞過那道門的方法。
- **連結本身就是憑證。** 任何拿到它的人都讀得到這個頁面，所以請把它當密碼看待；當它要去一個你控制不了的地方時，加上 PIN 碼和到期日。
