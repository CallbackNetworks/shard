# 總覽

首頁把所有在等你注意的事收在一起。關於它最重要的一件事是：**它不是一份你讀完就離開的報表。上面每一個數字、每一行，都是通往它所指的那個東西的路。**

![總覽](/guide/01-overview.png)

## 上面那排卡片

逾期、進行中、本週完成等等。每一張都是一個問題，而點下去會用**實際的工作**來回答，不是用一張圖表。

![總覽縮到逾期的工作](/guide/02-overview-overdue.png)

點「逾期」，下面的清單就縮到剛好那些任務。頁面會用一條說明列告訴你，那條列上也放著回去的路。

這個縮小的狀態存在網址裡。所以重新整理還在、瀏覽器的上一頁可以取消它，而且你可以把連結傳給別人，他看到的跟你一樣。

### 「逾期」是什麼意思

過了到期日，而且既沒完成也沒失敗。這是整個 app 通用的定義——總覽、分析頁、通知信、API 全部用同一個。失敗的任務不算遲到；它是失敗，而且被算在「失敗」那一欄。

## 四條線道

四組真正的任務：

- **Critical** —— 逾期或高優先。從這裡開始。
- **In Motion** —— 已經有人動起來了。
- **Waiting** —— 還沒有人接手。
- **Done today** —— 你今天做完的，所以這一天看得見底線。

點任何一個任務，它會**在自己的專案裡**打開，那一列會捲到畫面上並短暫亮起。如果專案頁上的篩選本來會把它藏起來，篩選會放寬——你要看的是那一個特定任務，看見它比保住一小時前設的篩選重要。

## 即時動態

右手邊那一欄：最近發生的所有事。任務完成、CI 回報建置結果、規則觸發。每一行都連到它所指的東西。

下面接著是你還開著的目標，以及還標著「待議」的決策——這兩種東西如果沒人看，就會安靜地卡住。

## 重新排它

這一頁上每一塊都是可以在**設定**裡關掉的區塊。如果你從來不用目標，把那一塊關掉，頁面就短了。什麼都不會不見——目標頁還在選單裡。

## 左邊那排選單

選單照你在做什麼分組：

| 群組 | 裡面有什麼 |
|---|---|
| **Operate** | 現在正在發生的事：總覽、結構圖、活動、分析 |
| **Think** | 目標、決策、樣板、助理 |
| **Build** | 整合、自動化規則、送達紀錄、API 金鑰 |
| **Data** | 原始的資料圖：資料瀏覽器與項目型別 |
| **System** | 身分、這份說明、設定 |

有兩件事是**刻意**不放在選單裡的。

**你要哪一個專案**是一個選擇，不是一個固定的目的地——所以它住在指令面板裡（`G` 再 `P`），而不是一個專案一列。

**身分聚焦**是一個控制項配上「你有幾個身分」那麼多的值，所以它自己佔一格放在選單上方，而不是每建一個身分就多一列。選單的高度不該是你放了多少資料的函數。
