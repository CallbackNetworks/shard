# 分析

六份報表，全部來自你已經記錄下來的工作。這裡沒有任何東西需要額外輸入資料。

![分析](/guide/08-analytics.png)

## 先決定要量什麼

上面那幾個框：第一個留在「所有專案」就是整體的樣子，或選一個專案來解鎖需要衝刺的那幾份報表。最後一個框決定趨勢線往回看多久——一週、一個月或三個月。

## 頭條數字

總數、完成、進行中、逾期。再加上本週最活躍的專案，那通常不是你以為的那個。

## 報表

**活動熱區圖** —— 一天一格，事情越多顏色越深。它顯示你每一週的形狀：你實際上哪幾天在工作，以及那些空隙。

**衝刺燃盡圖** —— 需要選一個有衝刺的專案。剩餘工作一天一天畫，對照一條直直降到零的線。兩條線之間的差距就是「我們趕得上嗎？」的答案，而頁面會用文字把它講出來，不是讓你自己去目測兩條線。

**速度** —— 你在過去每個衝刺完成了多少。跑過三四個衝刺之後，這比任何估計都更適合拿來規劃下一輪，因為它是由實際發生過的事組成的。

**狀態趨勢** —— 在你選的時間窗裡，各種數量怎麼變動。待辦線往上、完成線持平，是那種值得早點抓到的形狀。

**估計校準** —— 比較你估的時間和實際花掉的時間。它會回報一個整體比值，以及有幾件落在 20% 以內。大部分人都是穩定地錯一個固定倍數，而知道你自己的倍數，比努力估得更準有用。

## 有一份報表不在這一頁上

**關鍵路徑** —— 那條由相依任務組成、決定專案最快什麼時候可能結束的鏈 —— 是透過 API 和給 AI 代理用的，而不是這裡的一張圖。縮短**不在**那條鏈上的任何東西都不會讓日期提前，這就是它值得拿來問的原因。

## 把數字帶走

每一段都有一顆 **CSV** 按鈕。下載下來的檔案任何試算表都打得開，所以你想要另一種形狀的報表，只差一次下載，而不是一張功能需求單。

## 關於數字的意思

「逾期」在這裡的意思跟 app 其他地方一樣：過了到期日，而且既沒完成也沒失敗。

這些計數也包含**帶 task 角色的自訂型別**。如果你做了自己的項目型別並給了它 task 角色，它在這裡會跟內建任務被算得一模一樣。
