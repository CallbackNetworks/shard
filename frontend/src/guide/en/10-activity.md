# Activity and notifications

## The activity log

Everything that has ever happened, in one place.

![Activity](/guide/11-activity.png)

**Filtering.** The left column narrows by project and by kind of event. The number
beside each kind tells you how noisy it is before you click it.

**Three ways to read it.**

- **Timeline** spreads events across the last day, so bursts are visible as bursts.
- **Wall** groups them by what happened — useful for "what kind of thing has been
  going on?"
- **Log** is the plain reverse-chronological list.

**Every line goes somewhere.** Each entry names a task or a project and links to it,
so "what changed?" and "take me there" are one click apart.

**History outlives its subject.** Deleting a project does not delete its activity
record. Retiring the thing must not retire the account of what happened to it.

## Notifications

The bell in the corner collects things that need you: a task that just became
overdue, a build that failed, a rule that fired. Each one links to its subject, and
you can clear them individually or all at once.

## Reminders and summaries

These run on a schedule and are configured in **Settings**:

- **Due-date reminders** fire when a task is about to be due, and again when it goes
  overdue.
- **A daily summary email** goes out at an hour you choose.
- **A weekly digest** goes out on a day you choose.
- **SLA aging** escalates tasks that have sat untouched too long.

They go to the email integrations you have configured — see the chapter on
integrations for how to add one.
